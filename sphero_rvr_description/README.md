# sphero_rvr_description

[![ROS2 Jazzy](https://img.shields.io/badge/ROS2-Jazzy-blue)](http://wiki.ros.org/noetic/Installation/Ubuntu)

This package contains the RVR URDF description for ROS2.

The urdf folder contains the URDF description of the RVR robot. The meshes folder contains the STL files of the RVR robot.
